Here is a comprehensive system blueprint and design prompt for a state-of-the-art UI/UX tailored for an agentic, multi-agent orchestrator. This design focuses on deep visibility (individual vs. collective cognitive states) and dynamic interaction.

## 🏛️ System Architecture Blueprint: "The Hive-Mind Matrix"

To handle multiple agents, individual deep-dives, and aggregate group dynamics ("open claws" concurrent processing), the interface must abandon the classic linear ChatGPT-style stream. Instead, it relies on a **three-tier spatial canvas**:

```
+-----------------------------------------------------------------------+
|  [Side Panel]     |  [Center Canvas]               |  [Right Drawer]  |
|                   |                                |                  |
|  • Agent Registry |  • The Swarm Canvas            |  • Inspector     |
|  • Telemetry Logs |    (Graph Node Visualization)  |    (Single Agent |
|  • Active Threads |                                |     Deep-Dive)   |
|                   |  • Unified Stream / Split Tabs |                  |
+-----------------------------------------------------------------------+
|  [Bottom] Multi-Modal Command Bar (Global Target vs. Agent Routing)    |
+-----------------------------------------------------------------------+

```

## 🎨 Core UI/UX Feature Specifications

### 1. The Global "Swarm Canvas" (Group View)

* **Visual Representation:** A node-graph network showing active agents as floating, dynamic circles.
* **Data Pipelines ("Open Claws"):** When agents are processing simultaneously, animated data streams (glowing lines) connect them to the task breakdown.
* **State Indicators:** Nodes change color/pulse-rate based on their current computational state:
* *Green/Pulse:* Thinking/Executing.
* *Blue:* Awaiting dependency from another agent.
* *Purple:* Surfacing a manual human-in-the-loop (HITL) authorization request.


* **The Aggregator Stream:** A unified chat view where logs are color-coded by the agent who posted them, allowing you to see the group consensus building in real-time.

### 2. The "Inspector Drawer" (Individual View)

* **Action:** Clicking any node on the Swarm Canvas or a message avatar instantly slides out a right-hand drawer.
* **Individual Telemetry:** Inside this drawer, you see *only* what that specific agent is doing:
* **Internal Monologue:** A redacted or expandable raw text stream of its chain-of-thought (CoT) before it answers.
* **Tool Execution Matrix:** Current API calls, bash executions, or file-system mutations it is staging.
* **Context Window Gauge:** A simple progress bar showing how much of its local memory token limit is consumed.



### 3. Isolated & Global Interactivity (Talking to Them)

* **The Smart Command Bar:** Located at the bottom of the screen, featuring a dual-mode routing mechanism:
* `Global Prompt:` Sent to the orchestrator to delegate across the entire swarm.
* `Targeted Prompt (@AgentName):` Context-switches the input bar into a direct, encrypted command line to *just* that agent, bypassing group consensus.


* **Split-Screen Sandbox:** The ability to drag two agents out of the canvas into a side-by-side terminal view to watch them debug, cross-examine, or collaborate with each other based on your real-time prompts.

## ⚡ UX micro-interactions to implement:

* **Hovering over an agent node** highlights all the messages they have contributed to the main chat thread while dimming the rest.
* **Pressing `Tab` in the input bar** cycles through active agents (`@coder`, `@architect`, `@analyst`) for ultra-fast keyboard routing.
* **A "Pause Swarm" hotkey (`Spacebar` during runtime)** freezes all concurrent executions instantly, leaving their "claws" open so you can modify variables or redirect individual agents mid-thought.
