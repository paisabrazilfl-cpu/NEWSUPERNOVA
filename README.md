# BRENT-SITES-

Premium static landing page for a Roblox-related family claim review intake funnel.

## What is included

- `index.html` — polished responsive landing page
- `assets/styles.css` — premium dark/glass/gold UI system
- `assets/app.js` — form validation, UTM capture, and webhook-ready payload
- `assets/og-card.svg` — social preview graphic
- `robots.txt` — crawler/ad bot policy
- `llms.txt` — AI crawler summary
- `sitemap.xml` — static sitemap

## Production setup

1. Replace the placeholder `ENDPOINT` in `assets/app.js` with your secure intake webhook/backend.
2. Replace public URLs in `robots.txt`, `llms.txt`, and `sitemap.xml` if using a custom domain.
3. Enable GitHub Pages or deploy the repo to Vercel, Netlify, Render Static Sites, or Cloudflare Pages.
4. Add privacy policy, terms, and jurisdiction-specific attorney advertising review before running paid ads.

## Compliance notes

This site intentionally avoids promises of compensation, legal acceptance, or guaranteed results. It tells users this is attorney advertising and that form submission does not create an attorney-client relationship.
